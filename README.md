# Timesheet — đã chuyển sang Bộ công cụ dự án

Timesheet nay là một chức năng của **Bộ công cụ dự án** (repo [`TrackingTS`](https://github.com/xaxa9ztb/TrackingTS)):

- Mở: <https://xaxa9ztb.github.io/TrackingTS/> → đăng nhập → **Timesheet cá nhân**
- Mã nguồn hiện tại: `TrackingTS/tools/timesheet/` (đã gộp kèm toàn bộ lịch sử commit của repo này)

Trang GitHub Pages của repo này chỉ còn **tự chuyển hướng** sang địa chỉ mới.
Dữ liệu chấm công đã lưu trên trình duyệt vẫn còn nguyên (cùng địa chỉ `xaxa9ztb.github.io`).

> Mọi chỉnh sửa Timesheet từ nay làm trong repo `TrackingTS`. Repo này có thể *Archive*.
